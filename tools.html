Useful browser extensions

Small Chrome extensions I built for my own work. They run entirely in your browser and aren't on the Chrome Web Store, so you install them by hand.

How to install

Chrome · Edge · Brave · about a minute

Each extension comes as a .zip file. You unzip it, switch on Developer mode, and point the browser at the unzipped folder.

  1. Download the extension's .zip file using the button on its card below.
  2. Unzip it by double-clicking the file. Move the folder somewhere permanent, such as Documents. The browser loads the extension from this folder, so don't delete it later.
  3. Open the extensions page by typing chrome://extensions in the address bar. In Edge use edge://extensions; in Brave use brave://extensions.
  4. Turn on Developer mode with the toggle in the top-right corner (bottom-left in Edge).
  5. Click “Load unpacked” and select the unzipped folder, the one that contains manifest.json.
  6. Pin it by clicking the puzzle-piece icon in the toolbar, then the pin next to the extension. Its icon now sits in your toolbar, ready to click.

To update, replace the folder with the new version and click the ⟳ reload button on the extension's card in chrome://extensions. To remove it, click Remove there.
